# Data provenance

Every figure the chart renders is generated by `tools/build_data.py` directly
from the official Estimates PDFs in `sources/`. The build reconciles each figure
against the totals printed in those documents and **exits non-zero rather than
emitting a file if any check fails**, so `data/*.json` cannot drift from the
source silently.

```
pip install pdfplumber
python3 tools/build_data.py
```

The 2026-27 book is a **draft**. Its figures can change before the Estimates are
passed, and the page labels them as draft.

## What the build checks

For each year, all six of these must hold exactly:

1. Revenue lines sum to the printed `Total Current Revenue`.
2. That total matches the figure on the book's cover page.
3. The ten functional-classification lines sum to the printed `TOTAL EXPENDITURE`.
4. That total matches the cover page.
5. `Interest Expense + Expenses of Loans + Debt Amortization = Debt service`.
6. Debt service nests inside General Public Services — verified by confirming
   that everything except amortisation adds back to total expenditure less
   amortisation.

Current status: **all checks pass for both years.**

| --- | --- | --- |
| Total current revenue | 3,980,678,646 | 5,075,888,040 |
| Total expenditure (cover page) | 5,179,219,577 | 5,875,116,133 |
| Debt amortisation, excluded | 1,067,400,111 | 781,762,739 |
| Expenditure shown on the chart | 4,111,819,466 | 5,093,353,394 |

## Two decisions worth knowing

**Amortisation is excluded.** The cover page's "Total Expenditure" includes
repayment of loan principal, which is a financing item, not a service delivered
to anyone. Including it would double-count borrowing against the revenue side
and make the deficit meaningless. The chart therefore shows expenditure less
amortisation, states the excluded amount on the page, and records both figures
in each data file under `meta.reconciliation`.

**Spending categories are the government's own.** The right-hand side is the
official functional (COFOG) classification from Table 5, relabelled in plain
language — not an editorial grouping. Each category records the official
function(s) it sums in its `from` field, shown on hover. Two categories combine
functions (housing + environmental protection; public order + defence), and
`Running the government` is General Public Services with debt service removed.

## Corrections this exercise produced

The figures the chart carried before this build were **not** from these
documents and did not match them.

| Category | Was shown | Official FY2025/26 | Error |
| --- | --- | --- | --- |
| Education | 289.80 | 738.97 | understated by 61% |
| Healthcare | 376.20 | 379.46 | ≈ correct |
| Welfare / social protection | 650.00 | 83.46 | overstated ~7.8× |
| Public administration | 1,041.91 | 935.21 | overstated by 11% |
| Debt interest | 718.02 | 720.44 | ≈ correct |
| Property (revenue) | 226.38 | 285.74 | understated by 21% |
| International trade (revenue) | 285.78 | 302.49 | understated by 6% |
| Total revenue | 3,864.51 | 3,980.68 | understated by 116.17 |

Two consequences:

1. **"Debt interest is 2.5× education spending" was wrong.** On official figures
   debt interest (720.44) is slightly *less* than education (738.97), a ratio of
   0.97×. The claim was an artefact of an education figure that was too low by
   more than half. The page now compares debt interest against healthcare, where
   the 1.9× ratio does hold, and the comparison is generated from the data rather
   than written by hand.

2. **The old `International trade` value of 285.78 is within 0.04 of the official
   `Property` figure of 285.74.** That looks like a mislabelling in whatever
   source the earlier figures came from, not a coincidence. It no longer affects
   the page, but it is worth knowing if those numbers were published elsewhere.

## Still open

- **Population is unverified.** The build uses 261,692 (Barbados Statistical
  Service, end-2025). The World Bank puts 2025 near 282,600 — an ~8% spread that
  moves every per-resident figure. Confirm against the current BSS publication.
- **The 2026-27 book has an internal inconsistency** in Table 5: its
  year-on-year difference column does not tie to its own totals, by 2,357,361.
  The Estimates column itself reconciles exactly, and that is what the build
  uses, so this does not affect the chart.
- **Mid-Year Review not incorporated.** The earlier figures cited a Mid-Year
  Review; that document is not in `sources/`. Adding it would allow an
  approved-vs-revised-vs-outturn comparison.
